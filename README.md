# 📊 DataTracker - 个人数据追踪分析应用

## 🎯 功能特点

- ✅ 数据可视化（折线图、柱状图、饼图）
- ✅ 统计分析（总计、平均、极值、趋势）
- ✅ 本地数据持久化存储
- ✅ PWA 应用支持（可添加到手机桌面）
- ✅ 离线访问功能
- ✅ 响应式设计（支持手机和电脑）

## 🚀 快速开始

### Web 版本
访问演示地址或部署到您自己的服务器。

### 部署到 Netlify
1. 访问 https://app.netlify.com/drop
2. 拖入 `dist` 文件夹
3. 获得访问链接
4. 添加到手机主屏幕

## 📱 支持平台

- ✅ iOS Safari
- ✅ Android Chrome
- ✅ 桌面浏览器（Chrome、Firefox、Safari、Edge）

## 💻 技术栈

- React Native
- React Navigation
- React Native Chart Kit
- AsyncStorage
